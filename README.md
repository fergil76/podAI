# podAI - Versión con Splash + Rediseño

Esta versión de **podAI** incluye:
- Splash screen con logo temporal 🌱 y nombre podAI (usando expo-splash-screen).
- Pantallas rediseñadas con botones modernos, tarjetas y galería tipo grid.
- Mock de identificación IA aún presente (para pruebas).

## Ejecución
1. Instala dependencias:
   ```bash
   npm install
   ```
2. Inicia la app:
   ```bash
   npm start
   ```
3. Abre con Expo Go en tu dispositivo.
